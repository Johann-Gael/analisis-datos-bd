# analisis-datos-bd

This analytical study aims to answer the following three questions:

1. Do discounts actually reduce cancellations or increase bookings?
2. Which platform is the most profitable once cancellations are taken into account?
3. Which factors are associated with cancellations?




En esta base de datos se busca responder las siguiente preguntas:
1. ¿Los descuentos realmente reducen las cancelaciones o aumentan las reservas?
2. ¿Qué plataforma es más rentable si descontamos las cancelaciones?
3. ¿Qué factores se asocian con las cancelaciones?
